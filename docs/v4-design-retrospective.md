# 官网 V4 设计复盘与资产分类

## 设计原则

- 全宽画布承载品牌氛围，正文通过响应式页边距控制阅读宽度，不再使用居中的固定网页盒子。
- 以黑色、低饱和青色和半透明白为主色，洋红仅作为光子水体中的少量能量点缀。
- 标题采用左对齐编辑式排版；英文眉题、章节编号和细分隔线承担信息导航。
- 既有产品、案例、新闻、公司、合作伙伴和联系数据继续由原组件及数据文件维护，视觉层不复制业务数据。
- 动效必须支持离屏暂停、降低动态效果和移动端降级，不以持续高负载换取视觉密度。

## 本轮复盘

V4 首屏建立了足够鲜明的品牌视觉，但旧版正文仍采用居中胶囊标题、固定 `max-w-7xl` 和大量圆角卡片，导致首屏与内容区割裂。本轮将首页产品、案例、新闻、页脚以及案例/新闻/联系列表页统一为全宽编辑式系统，同时保留所有原始数据和交互入口。

网站地图采用编号索引矩阵作为全站信息架构模板；联系我们采用总部信息、城市网络、二维码、合作方向和 CTA 五级结构。企业价值观保持独立章节，避免内容区块相互嵌套造成视觉和语义层级混乱。

公司基因与发展历程不再使用独立的蓝紫科技面板。两者沿用首屏背景和光子水流语义，以平面刻度、单线流光和低对比节点完成从品牌主张到公司历史的连续叙事。

本轮进一步将这套语言扩展到全站：背景统一为深黑水域，章节通过低密度青色与洋红光子保持连续；产品、案例、新闻、价值观、联系、网站地图及法律内容统一为单线平面矩阵。案例与新闻详情保留真实项目图片和产品界面的信息强度，但外围导航、标题、正文、推荐内容和咨询入口均回归黑白编辑式层级。

为避免视觉统一损害可用性，导航序号采用独立的 `aria-hidden` 装饰节点，不再由 CSS 生成内容参与可访问名称；复杂产品驾驶舱仅去除多余圆角和外发光，不改变积木选择、场景切换和产品大屏交互。

动画层曾因逐粒子阴影与逐点波纹计算阻塞浏览器主线程。当前实现采用约 25 FPS、批量路径填充、近场波纹计算和离屏暂停；后续扩展不得恢复逐粒子高斯阴影或无上限粒子密度。
