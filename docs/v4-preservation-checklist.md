# 官网 V4 路由与功能保留清单

## 页面与路径

- `/`：首页及 `#home`、`#company-gene`、`#products`、`#cw-cloud`、`#cw-visual`、`#cases`、`#news`、`#contact` 锚点。
- `/cases`：案例筛选、全国项目地图、项目定位点与案例列表。
- `/cases/[slug]`：11 个案例详情路径，以及同类案例推荐、更多案例和返回能力。
- `/news`：新闻列表与分页。
- `/news/[slug]`：16 个新闻详情路径，以及目录、上一篇/下一篇、推荐阅读和返回能力。
- `/contact`：公司介绍、企业价值观、地址、全国业务布局、二维码和商务合作方向。
- `/sitemap`：全站内容入口。
- `/privacy`：隐私政策。
- `/terms`：服务条款。

## 首页内容与交互

- 光子水体、水滴冲击、CYBERWATER 波纹折射与降低动态效果降级。
- 水务运营管理基因、公司数据、能力关系图。
- 2015、2018、2020、2022、2025、2026 六个发展里程碑及原始文案。
- CW-Cloud 水务 AI 运营平台、CW-Visual 三维数字孪生平台。
- 积木组合、11 个产品标签、产品大屏、数字孪生场景和模型族库交互。
- 四类解决方案筛选、全国案例地图、案例详情入口。
- 新闻头条、动态列表与新闻详情入口。
- 北京总部地址，深圳、成都、西安、上海城市展示。
- 企业微信、销售顾问二维码、合作伙伴、法律信息与网站地图入口。

## 全站公共能力

- 桌面导航激活状态、移动菜单和锚点跳转。
- 联系按钮与演示/咨询弹窗，可通过关闭按钮、遮罩和 Escape 关闭。
- 案例筛选、地图悬浮说明、地图与案例列表联动。
- 新闻列表分页、详情目录、返回新闻列表及前后文章导航。
- 桌面端与移动端响应式布局，无页面级横向溢出。
- 离屏动画暂停、系统降低动态效果支持。

## 数据与资源边界

- 案例继续由 `lib/cases.ts` 维护，未复制或替换为占位数据。
- 新闻继续由 `lib/news.ts` 维护，未复制或替换为占位数据。
- 产品、案例、新闻、合作伙伴、二维码和品牌图片继续复用 `public/` 中的现有资源。
- 本轮只调整视觉令牌、排版、表面样式和组件表现，不删除业务字段、内容入口或现有路径。

## 本轮验证

- `next build --webpack`：36 个静态页面全部生成。
- 桌面浏览器：首页产品、案例、新闻、页脚、列表页及详情页完成视觉检查。
- 手机视口：389 × 844 检查首页与案例、新闻、联系、案例详情、新闻详情、网站地图、隐私政策，无页面级横向溢出。
- 交互：产品标签切换、案例筛选、新闻返回、联系弹窗和移动菜单通过。
